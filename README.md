# GerAI

## 📌 Sobre o projeto

O **GerAI** é uma aplicação web que utiliza inteligência artificial para auxiliar na geração de páginas e conteúdos através de comandos personalizados.

O projeto foi desenvolvido com o objetivo de explorar a integração entre aplicações web e APIs de inteligência artificial, criando uma ferramenta capaz de interpretar solicitações do usuário e gerar resultados automaticamente.

---

## 🚀 Funcionalidades

- ✨ Geração de conteúdos utilizando Inteligência Artificial
- 🤖 Integração com API de IA
- 📝 Entrada de comandos personalizados pelo usuário
- ⚡ Processamento e exibição dos resultados
- 🎨 Interface simples e intuitiva

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SamuelOlDourado/GerAI.git
```

### 2. Acesse a pasta do projeto

```bash
cd GerAI
```

### 3. Crie um ambiente virtual

```bash
python -m venv venv
```

### 4. Ative o ambiente virtual

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### 5. Instale as dependências

```bash
pip install -r requirements.txt
```

### 6. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto:

```env
GROQ_API_KEY=sua_chave_api
```

### 7. Execute a aplicação

```bash
python app.py
```

A aplicação estará disponível em:

```
http://127.0.0.1:5000
```
